FAQ

Frequently asked questions.

Everything you need to know about NeoChems multi-agent scientific intelligence system.

NeoChems is a stateful multi-agent scientific intelligence system designed for chemistry research, reasoning, route planning, validation, and discovery. Rather than a single conversational model, it orchestrates a collaborative workforce of specialized agents with shared state and continuous validation.

NeoChems is not a chatbot that generates a single unverified text response. It is an observable multi-agent runtime where specialized agents decompose objectives, execute parallel tasks, consult external chemistry tools, challenge weak conclusions via a critic loop, and provide fully inspectable evidence.

A multi-agent system coordinates multiple autonomous software agents, each specialized in a specific discipline—such as literature retrieval, chemical route planning, property analysis, or scientific validation. They communicate through structured messages and maintain shared state toward a common objective.

The Orchestrator receives the objective and generates a task graph. Specialized agents (Research, Retrosynthesis, Analysis, Knowledge) execute assigned subtasks, passing intermediate results to Validation and Critic agents. If contradictions or infeasibilities are detected, the Orchestrator initiates an automatic replanning loop.

The Orchestrator coordinates the entire run. It receives the user's research objective, constructs the execution plan, delegates tasks, monitors agent states, manages dependencies, aggregates findings, and triggers replanning whenever the Critic or Validation agent flags an issue.

Yes. Agents interface with normalized chemistry tools and libraries including RDKit, reaction search indices, property calculators, and retrosynthesis engines through a governed Tool Registry with input validation and execution tracking.

Agent errors become explicit runtime events rather than crashing the system. If an agent times out or encounters conflicting data, the error is broadcasted to the Orchestrator, which logs the failure, updates shared state, and triggers an alternate execution path or replanning.

Every recommendation and reaction transformation is linked to verifiable sources, reaction records, literature citations, or computed properties. The system exposes how an answer was produced and what supports it, maintaining transparent scientific traceability.

The Chemistry workspace is a dedicated scientific domain interface featuring molecular structure exploration, retrosynthetic disconnection trees, reaction evidence retrieval, physicochemical property estimation, and aqueous solubility profiling.
